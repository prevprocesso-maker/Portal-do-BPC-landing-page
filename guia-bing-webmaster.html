Submeter o sitemap no Bing.

O Bing alimenta o Yahoo, o ChatGPT Search, o Copilot e o DuckDuckGo. Submeter o sitemap leva 10 minutos e abre uma frente extra de tráfego além do Google.

~5%
do tráfego brasileiro de busca vem do Bing + Yahoo
100%
das buscas do ChatGPT (modo busca) e Copilot passam pelo Bing
27
URLs do Portal do BPC prontas pra indexação
Antes de começar Tenha em mãos: conta Microsoft (a mesma do Outlook/Hotmail/Xbox serve), acesso ao Google Search Console do site (atalho de 1 clique se quiser pular a verificação manual), e o site portaldobpc.com.br já no ar.
1

Criar conta no Bing Webmaster ToolsGratuito. Não precisa de cartão.

a

Acesse:

https://www.bing.com/webmasters
b

Clique em "Entrar" (canto superior direito).

Pode entrar com Microsoft, Google ou Facebook. Use Google se já tiver o Google Search Console configurado — vai facilitar o passo 3.

c

Aceite os termos. Você vai cair na tela inicial pedindo pra adicionar um site.

2

Adicionar o site — escolha o caminho mais fácilO Bing dá 2 opções. A primeira economiza 100% do trabalho.

Recomendado

Importar do Google Search Console

Botão grande na tela: "Importar do GSC".

Ele puxa o site, a verificação e o sitemap automaticamente. Tempo: 60 segundos.

Adicionar manualmente

Caso não tenha o GSC ainda, clique em "Adicionar site" e cole a URL.

Aí o Bing pede pra verificar a propriedade (passo 3).

URL exata pra colar (sempre com https e www):

https://www.portaldobpc.com.br
Importante Se você adicionou via "Importar do GSC", pule pro passo 4 — o sitemap já entrou junto. Se foi manual, siga pro 3.
3

Verificar a propriedade — só se foi manualComprovar pro Bing que o site é seu.

O Bing oferece 3 métodos. Escolha o que você já tem acesso:

A

Arquivo XML — baixa um arquivinho BingSiteAuth.xml e sobe na raiz do site.

No Portal do BPC, a raiz é deploy/ — basta colocar lá e fazer commit no GitHub. A Vercel publica em 30 seg.

B

Meta tag — cola uma tag <meta name="msvalidate.01"> dentro do <head>.

No Portal do BPC, vai em deploy/index.html, dentro de <head>, logo depois das outras meta tags. Me manda a tag e eu insiro pra você.

C

CNAME no DNS — registro no Registro.br. Funciona, mas leva mais tempo (até 4h pra propagar). Evite essa.

Depois de subir o método A ou inserir o método B → volta no Bing → clica em "Verificar".

4

Submeter o sitemapÉ o que diz pro Bing quais 27 URLs ele deve rastrear.

a

No painel lateral esquerdo, clique em "Sitemaps".

b

Clique em "Enviar sitemap" (botão no topo direito).

c

Cola a URL completa do sitemap:

https://www.portaldobpc.com.br/sitemap.xml
d

Clique em "Enviar".

Em poucos segundos vai aparecer status "Sucesso" com "27 URLs descobertas".

Pronto! O Bing começa a rastrear em 24-72 horas. Em 5-10 dias todas as URLs aparecem no índice.
5

Ativar o IndexNow (turbo de indexação)Avisa os motores quando você publica algo — em vez de esperar dias.

O IndexNow é um "telefone direto" pros motores de busca. Em vez de esperar o robô passar (24-72h), você liga avisando quando publica/atualiza/deleta uma página. Usado por Bing, Yandex, DuckDuckGo, Seznam e Naver — você ativa uma vez, ganha 5 motores.

Caminho A — Toggle no painel (recomendado agora)

a

No Bing Webmaster Tools, menu lateral → "IndexNow".

b

Liga o toggle. O Bing detecta sozinho quando o sitemap muda e avisa os outros motores. Sem código.

Pré-requisito — Arquivo de chave (já feito)

Pra IndexNow funcionar (toggle ou API), o site precisa hospedar um arquivo de chave na raiz que prova que você é o dono. Já foi criado pra você em deploy/a7f3c92d8e4b461fa05d7c89b3e2f146.txt.

Quando você der commit, vai ficar acessível em:

https://www.portaldobpc.com.br/a7f3c92d8e4b461fa05d7c89b3e2f146.txt

Conteúdo do arquivo (uma única linha):

a7f3c92d8e4b461fa05d7c89b3e2f146
Guarde essa chave a7f3c92d8e4b461fa05d7c89b3e2f146 — você vai precisar dela se quiser usar o Caminho B (API) no futuro. Salve no STATUS.md.

Caminho B — API programática (só quando blog estiver ativo)

Pra cada URL nova/atualizada/deletada, você dispara uma chamada HTTP e o motor indexa na hora. Não precisa fazer agora. Vale só quando estiver publicando 2+ posts por semana.

Enviar uma URL (GET):

https://api.indexnow.org/indexnow?url=https://www.portaldobpc.com.br/blog/seu-post&key=a7f3c92d8e4b461fa05d7c89b3e2f146

Enviar várias URLs (POST JSON, até 10.000 por vez):

POST https://api.indexnow.org/indexnow Content-Type: application/json; charset=utf-8 { "host": "www.portaldobpc.com.br", "key": "a7f3c92d8e4b461fa05d7c89b3e2f146", "urlList": [ "https://www.portaldobpc.com.br/blog/post-1", "https://www.portaldobpc.com.br/blog/post-2" ] }

Códigos de resposta esperados:

✓

200 OK — URL recebida com sucesso.

~

202 Accepted — Recebida, validação da chave pendente.

✗

400 formato inválido · 403 chave inválida · 422 URL fora do host · 429 muitas requisições.

Recomendação Hoje, só liga o toggle (Caminho A). A API (Caminho B) entra na pauta quando o blog estiver com volume.
6

Acompanhar nos próximos diasO que olhar e quando começar a se preocupar.

Nos primeiros 14 dias, dê uma olhada 2× por semana em:

›

Painel → Visão geral. Veja se "Páginas rastreadas" sobe de 0 pra 27 (ou perto).

›

Sitemaps. Status deve ficar "Sucesso", número de URLs descobertas deve bater com 27.

›

Inspeção de URL (menu lateral). Cole qualquer URL do site e veja se está indexada. Se der "Não indexada" depois de 7 dias, clique em "Solicitar indexação".

Esperado normal Levar até 30 dias pra todas as 27 URLs aparecerem indexadas. O Bing é mais lento que o Google nas primeiras semanas, mas depois estabiliza.
