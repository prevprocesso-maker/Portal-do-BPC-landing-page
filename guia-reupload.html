Re-upload limpo do GitHub · passo a passo

Como reconstruir o repositório do GitHub do zero.

Guia completo para apagar tudo o que está no GitHub e reenviar a versão correta e organizada, sem riscos. Siga na ordem. Imprima e marque cada passo conforme for completando.

01

Apagar TUDO do repositório (sem perder o repo)

NÃO use "Settings → Delete repository". Você perderia o repo, a integração com Vercel e o domínio teria que ser reconectado.
  1. Acesse github.com/prevprocesso-maker/Portal-do-BPC-landing-page
  2. Para cada arquivo na lista: clique no arquivo
  3. No canto superior direito do código, clique nos 3 pontinhos (⋯) ou no ícone de lixeira
  4. Selecione "Delete file"
  5. Caixa de commit: escreva "limpa"
  6. Clique "Commit changes"
  7. Volte para a raiz e repita com o próximo arquivo
Para pastas (assets/): entre dentro e delete cada arquivo. Quando o último sair, a pasta some sozinha.
NÃO apague: README.md (opcional manter) e .gitignore se houver.
02

Confirmar que a tradução do Chrome está DESLIGADA

CRÍTICO: Se a tradução automática estiver ligada, ela vai renomear os arquivos (foi o erro anterior — pasta virou "ativos" e arquivos ficaram em português).
  1. Chrome: clique nos 3 pontinhos (⋮) no canto superior direito
  2. Vá em Configurações
  3. Menu lateral: Idiomas
  4. Desligue "Oferecer tradução de páginas que não estão em um idioma que eu leio"
03

Descompactar o ZIP no seu PC

  1. Clique com o botão direito no ZIP baixado
  2. Selecione "Extrair tudo" / "Extract all"
  3. Vai criar uma pasta deploy/ com a estrutura completa

04

Upload organizado no GitHub

  1. Com o repositório vazio no GitHub, clique em "Add file" → "Upload files"
  2. No seu PC, ABRA a pasta deploy/ (entre dentro dela)
  3. Pressione Ctrl + A para selecionar TODOS os arquivos e a pasta assets/
  4. Arraste tudo para dentro da janela do GitHub
  5. O GitHub vai mostrar a estrutura: assets/imagem.jpg, index.html, etc.
  6. Caixa de commit: escreva "Re-upload completo e organizado"
  7. Clique "Commit changes"
Atenção: Você arrasta o conteúdo da pasta deploy/ (não a pasta deploy/ em si). Se você arrastar a pasta inteira, vai ficar errado: Portal-do-BPC-landing-page/deploy/index.html — quando deveria ser Portal-do-BPC-landing-page/index.html.
05

Verificar se tudo subiu

Após o commit, espere 30 a 60 segundos (Vercel redeploya automaticamente).

Abra em aba anônima: https://www.portaldobpc.com.br

Confira:

  • ✅ Logo aparece no header
  • ✅ Sua foto aparece no hero
  • ✅ As 4 fotos do escritório aparecem na seção "Nosso espaço"
  • ✅ Footer mostra "FAZ PARTE DO ESCRITÓRIO · CarlosCostaPrev"
  • ✅ Página de Perícias funciona
  • ✅ Página de BPC Estrangeiro funciona
  • ✅ Pesquisa nas FAQ funciona
  • ✅ Avaliações com QR code no rodapé
06

Submeter sitemap no Google Search Console

Já está verificado. Falta apenas submeter o sitemap:

  1. Acesse search.google.com/search-console
  2. Selecione a propriedade https://www.portaldobpc.com.br/
  3. Menu lateral: clique em Sitemaps
  4. No campo "Adicionar um novo sitemap" digite: sitemap.xml
  5. Clique ENVIAR
  6. Em 24-72 horas o Google começará a indexar 27 URLs
