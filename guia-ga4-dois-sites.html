Guia prático · Analytics multi-site

GA4 para os 2 sites do ecossistema.

Hoje o Google Analytics mede só o Portal do BPC. Esse guia mostra como ampliar pra também medir o CarlosCostaPrev — embaixo da mesma conta, com relatórios separados, sem misturar audiências.

Pré-requisito A conta GA4 (CarlosCostaPrev) e a propriedade Portal do BPC já estão criadas, com o Measurement ID G-6RVLVTFRGT ativo no www.portaldobpc.com.br. Esse guia é só pra adicionar o segundo site.
1

Como vai ficar a estrutura1 conta guarda-chuva, 2 propriedades independentes.

No GA4 a hierarquia é: Conta → Propriedade → Fluxo. A regra que vamos seguir:

🏢 CONTA: CarlosCostaPrev (guarda-chuva)
   │
   ├── 📍 PROPRIEDADE: Portal do BPC                [✓ JÁ FEITO]
   │      └── 🌊 Fluxo Web: www.portaldobpc.com.br
   │             ID: G-6RVLVTFRGT
   │
   └── 📍 PROPRIEDADE: CarlosCostaPrev              [⏳ CRIAR AGORA]
          └── 🌊 Fluxo Web: www.carloscostaprev.com.br
                 ID: G-________ (vai ser gerado)
Por que 1 conta só Os dois sites pertencem ao mesmo ecossistema empresarial. Manter na mesma conta facilita gestão de usuários, faturamento (caso vire pago um dia), e permite comparar performance entre as marcas no futuro.
2

Por que 2 PROPRIEDADES e não 2 FLUXOSA decisão técnica que muda muito os relatórios.

O GA4 oferece 2 jeitos de medir mais de um site:

As 2 opções e quando usar cada uma

❌ Não é o nosso caso 1 propriedade + 2 fluxos

Usa quando: mesma marca em 2 plataformas (ex: site + app, ou domínio principal + subdomínio).

❌ Mistura audiências: BPC + escritório geral em um único pote — relatórios não distinguem.

✅ É o nosso caso 2 propriedades separadas

Usa quando: marcas distintas com audiências, objetivos e conversões diferentes.

✅ Relatórios independentes. Comparação entre marcas. Search Console separado.

Pensa assim:

  • Portal do BPC é uma marca vertical, focada em BPC/LOAS, com público-alvo idosos 65+ e familiares de PCD.
  • CarlosCostaPrev é uma marca horizontal, com toda previdência (aposentadorias, pensões, INSS em geral).
  • Visitantes, intenções, palavras-chave e taxas de conversão são bem diferentes. Misturar tudo num saco só faz perder leitura.

Plugar o código no site do CarlosCostaPrevDepende de onde esse site está hospedado.

O snippet do GA4 é praticamente o mesmo do Portal do BPC, só trocando o ID:

<!-- Cola dentro de <head>, antes de </head> -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-SEU_ID_AQUI"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('consent', 'default', {
    'analytics_storage': 'denied',
    'ad_storage': 'denied'
  });
  gtag('config', 'G-SEU_ID_AQUI', { 'anonymize_ip': true });
</script>

Onde colar:

A

Se o CarlosCostaPrev está na mesma estrutura do Portal do BPC (Vercel + GitHub, HTML estático):

  • Abre o repositório no GitHub
  • Edita o index.html (e qualquer outro .html que exista)
  • Cola o snippet acima dentro do <head>
  • Commit → Vercel redeploya em ~60s
B

Se for WordPress:

  • Painel WP → Plugins → Adicionar novo → instala "Site Kit by Google" (oficial)
  • Ativa o plugin → faz login com a conta Google → conecta com a propriedade CarlosCostaPrev → pronto
C

Se for Wix / Squarespace / outro construtor:

  • Procura "configurações → SEO ou Analytics"
  • Tem um campo direto pra colar o Measurement ID (formato G-XXXXXXXXXX)
  • Não precisa colar o snippet inteiro — só o ID
D

Se for hospedagem tradicional (cPanel, FTP):

  • Conecta no FTP/gerenciador de arquivos
  • Edita index.html (ou header.php se for WordPress sem plugin)
  • Cola o snippet dentro do <head>
  • Salva e sobe
Atenção — banner LGPD Se o site CarlosCostaPrev não tem banner de cookies LGPD, o GA4 vai capturar dados sem consentimento — risco jurídico. O Portal do BPC tem o banner pronto. Pro CarlosCostaPrev, ou copia o mesmo banner, ou usa um plugin pronto (Cookiebot, OneTrust grátis).

Em 30 min você monta um relatório com: Total de leads BPC + Total de leads CarlosCostaPrev, gráfico comparativo de tráfego, fontes principais, etc.

2

Roll-up Property — feature paga (GA360). Pula essa, não vale pra escritório pequeno.

Quando estiver pronto pra montar o dashboard comparativo no Looker, me avisa que faço uma versão pré-pronta pra você.
