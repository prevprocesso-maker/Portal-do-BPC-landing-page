1

Criar conta no Google AnalyticsGratuito. A versão paga (GA360) é coisa de empresa de e-commerce gigante — não é o nosso caso.

a

Acesse:

https://analytics.google.com
b

Faça login com o Google. Se for a primeira vez, vai aparecer uma tela "Começar a medir" com um botão azul. Clique.

c

Se já tiver outras contas do GA (de outros sites), aparece no canto superior esquerdo um seletor de conta — clique no símbolo de engrenagem ⚙ Administrador no canto inferior esquerdo e depois em "+ Criar" → "Conta".

4

Criar o fluxo de dados — pegar o Measurement IDÉ aqui que o ID nasce. Anota com carinho.

a

Na tela "Comece a coletar dados", escolha "Web" (não App).

b

Preencha o fluxo:

URL do site
https://www.portaldobpc.com.br (escolha https:// no dropdown)
Nome do fluxo
Portal do BPC — Site
Medição aprimorada
Deixe ligada (já vem por padrão). Ela mede automaticamente: page_view, scroll 90%, cliques em links externos, busca interna, vídeo, download de arquivos. Tudo grátis sem código.
c

Clique em "Criar fluxo".

d

A próxima tela mostra os detalhes do fluxo. Localize o campo "ID de medição" no canto superior direito. Tem o formato:

G-XXXXXXXXXX

Copia esse valor (o seu real, não o placeholder). Guarda num bloco de notas. É o que você vai colar no index.html no próximo passo.

Atenção Não confunda "ID de medição" (G-XXXX…) com "ID do fluxo" (número longo de 10 dígitos). É o primeiro que vai no código.
5

Colar o ID no index.html2 lugares. Pode fazer direto pelo GitHub Web — sem clonar repositório.

a

Acesse o repositório no GitHub:

https://github.com/prevprocesso-maker/Portal-do-BPC-landing-page
b

Clique em index.html na lista de arquivos.

c

No canto superior direito do arquivo, clique no ícone de lápis ✏️ ("Edit this file"). Vai abrir o editor de código.

d

Aperte Ctrl + F (Win) ou ⌘ + F (Mac) pra buscar dentro do arquivo. Procure por:

G-XXXXXXXXXX

Você vai achar 2 ocorrências. Troca as duas pelo ID que você copiou no passo 4.

e

Confere se ficou parecido com isso (substituindo G-AB1C2D3E4F pelo seu ID real):

<!-- linha ~51 -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-AB1C2D3E4F"></script>

<!-- linha ~61 -->
gtag('config', 'G-AB1C2D3E4F', { 'anonymize_ip': true });
f

Role até o final da página. Em "Commit changes":

  • Mensagem do commit: feat: adiciona GA4 measurement ID
  • Mantém marcada a opção "Commit directly to the main branch"
  • Clica no botão verde "Commit changes"
O que acontece em seguida A Vercel detecta o commit em ~10 segundos e dispara um deploy automático. Em ~60 segundos o site já está no ar com o GA4 ativo. Não precisa fazer nada.
6

Verificar que está funcionando2 jeitos. O segundo (DebugView) é mais confiável.

Rápido

Relatório em tempo real

Abre www.portaldobpc.com.br numa aba anônima. Aceita os cookies no banner que aparece.

No GA4: menu lateral → "Relatórios" → "Tempo real". Deve aparecer "1 usuário nos últimos 30 minutos" em até 60 segundos.

Detalhado

DebugView (precisa de extensão)

Instale a extensão "Google Analytics Debugger" no Chrome. Ativa ela e abre o site.

No GA4: Administrador → "DebugView". Aparecem todos os eventos em tempo real (page_view, scroll, click, etc) com timeline detalhada.

Se não aparecer ninguém em "Tempo real" Três coisas pra checar:
  1. Você aceitou os cookies no banner? O consent mode bloqueia o envio até aceitar — esse é o comportamento correto, mas faz parecer quebrado.
  2. Está usando algum bloqueador de anúncios (uBlock, AdBlock, Brave Shields)? Eles bloqueiam o GA4. Teste em aba anônima sem extensões.
  3. O ID foi salvo nos dois lugares? Veja em view-source:www.portaldobpc.com.br se aparece o seu G-XXXX… real (e não o placeholder).
7

Conectar com o Search ConsoleFaz no GA4, ativa de tabela no GSC. 2 cliques.

Depois que o GSC estiver configurado (próximo guia), volte aqui:

a

GA4 → Administrador → coluna "Propriedade" → role até "Links de produtos" → "Search Console".

b

Clique em "Vincular" → selecione www.portaldobpc.com.br → escolha o fluxo "Portal do BPC — Site" → confirma.

Por que vincular Depois dessa ligação, o GA4 mostra dentro dele quais buscas no Google levaram à página (relatório "Aquisição → Search Console"). Sem o vínculo, esses dados ficam ilhados no GSC.
8

Marcar eventos importantes como conversãoPra medir o que importa, não só tráfego bruto.

No GA4 você tem que dizer manualmente "este evento é uma conversão". O Portal do BPC tem 2 conversões claras:

1

Clique no WhatsApp float — sinal mais forte de intenção de contato. Já dispara automaticamente como click via medição aprimorada (cliques em links externos).

2

Submissão do formulário de "Análise Gratuita". Aqui precisa adicionar uma linha no código pra disparar um evento custom. Posso fazer isso pra você depois — me avisa.

Pra marcar um evento como conversão:

›

GA4 → Administrador → "Eventos" → encontra o evento (depois que ele aparecer pela primeira vez nos dados, leva ~24h) → toggle "Marcar como conversão".

Espere 24-48h Eventos só aparecem na lista depois que dispararam ao menos 1 vez. Então nas primeiras 24h, a lista vai estar quase vazia — isso é normal.
